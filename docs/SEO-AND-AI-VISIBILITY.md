# SEO and AI-assistant visibility playbook

**Goal:** when someone in Delhi searches Google for tailbone pain, or asks ChatGPT, Gemini, Claude, Perplexity or Copilot "who treats tailbone pain without surgery in Delhi?", they find Tailbone Treatment Clinic and Dr Rajveer Singh.

Part A lists what's already built into the website. Part B lists the steps only you can do, most important first.

---

## A. Already done on the website

| What | Why it matters |
|---|---|
| **A real HTML page for every topic** (`/`, `/coccydynia`, `/treatment`, `/doctor`, `/locations`, `/faq`, `/book`). Each has its own title, description, canonical link and heading, and only its own content. | Before this, every address returned the same page. Google couldn't tell them apart, and AI crawlers (which usually don't run JavaScript) saw one long mixed page. |

They power rich results and help AI answers state facts correctly. |
| **"At a glance" facts** on the home page: what we treat, who, approach, where, hours, fees, how to book. | AI answer engines prefer short, factual, quotable statements. |
| **robots.txt names the AI crawlers**: GPTBot, OAI-SearchBot, ChatGPT-User, ClaudeBot, Claude-SearchBot, PerplexityBot, Google-Extended, Applebot-Extended, meta-externalagent and others. Public pages are open; admin, API and patient pages are closed. | Makes it explicit that the clinic wants to be found and cited. |
| **`/llms.txt` and `/llms-full.txt`**: a plain-text guide to the clinic and the full text of every page and article. | An emerging convention (llmstxt.org) that AI tools use to understand a site quickly. |
| **IndexNow** (`npm run indexnow`). | Tells Bing, which feeds **ChatGPT search** and **Microsoft Copilot**, plus Yandex and others, about new pages within hours. |
| **16 articles**: 12 by Dr Rajveer from the old site (2017–2026, original dates kept) plus 4 new ones, each with sources, author and disclaimer. | Depth on the topic, and a named expert author, are what both Google and AI assistants rank. |
| **"In the news" page** with 11 newspaper clippings (Times of India, Deccan Herald, Hindustan, Rajasthan Patrika, Prajavani, Salar…), and an "As featured in" strip. | Independent press coverage is one of the strongest trust signals for both search and AI. |
| **301 redirects from every old tailbonetreatment.com address** (old pages, articles, tags, categories). | When the domain moves, the old site's years of Google rankings and backlinks carry over instead of becoming 404s. |
| **Sitemap** listing every page and article, regenerated by `npm run build`. | |
| Fast, mobile-friendly, accessible pages (no accessibility errors; small pages; fonts and images optimised). | Page experience is a ranking factor. |

## B. Your steps, in order

### 1. Point tailbonetreatment.com to the new site (this week)
This is the single biggest SEO step. The domain has years of history, backlinks and press links that the netlify.app address doesn't.
1. In Netlify: **Domain management → Add a domain → tailbonetreatment.com** (and www). Netlify shows the DNS records to set.
2. At the domain registrar, change only the **website records** (A / CNAME) to Netlify's. **Leave the MX (email) records alone**, so contact@tailbonetreatment.com keeps working.
3. Tell me when it's live. I'll switch every canonical link, the sitemap, structured data and llms.txt to `https://tailbonetreatment.com`, run the build and push. The old-address redirects then start working.
4. Update the Google Ads final URLs (see `resources/google-ads/SEARCH-CAMPAIGN-PLAN.md`).

### 2. Google Search Console (30 minutes)
1. search.google.com/search-console → **Add property → Domain** → `tailbonetreatment.com` → add the TXT record it gives you at the registrar.
2. **Sitemaps** → submit `sitemap.xml`.
3. **URL inspection** → paste the home, `/coccydynia`, `/treatment`, `/doctor` and `/locations` URLs → **Request indexing** for each.
4. After 2–4 weeks, check **Performance** for which searches show the site, and **Pages** for any errors.

### 3. Bing Webmaster Tools (10 minutes, important for ChatGPT and Copilot)
1. bing.com/webmasters → **Import from Google Search Console** (one click once step 2 is done).
2. Submit the sitemap.
3. I run IndexNow after each update. You can also run `npm run indexnow` after a deploy.

Expect the first movement in Google after 4–8 weeks. AI assistants usually reflect changes within 1–3 months, faster for those that search the web live (ChatGPT search, Perplexity, Copilot).

## C. Things to avoid
- Buying backlinks or reviews, or posting fake ones.
- Publishing AI-written articles in bulk without Dr Rajveer's review: low-quality health content is penalised.
- Keyword-stuffed titles. Some old articles have them (e.g. "Bruised Tailbone | Fractured Tailbone"); tidy them gradually when Dr Rajveer reviews those articles.
- Medical claims like "cure", "guaranteed" or "100%".

## D. Maintenance (technical)
- **After editing pages or articles:** run `npm run build`, commit and push. Netlify deploys automatically.
- **After a deploy:** run `npm run indexnow`.
- **Page text** lives in `content/site.html`. **Articles** are in `content/blog/`. **Press clippings** are in `content/press.json`. **Old-address redirects** are in `content/redirects.json`.
- **Changing the domain:** `SITE_URL=https://tailbonetreatment.com npm run build` (or change the default in `scripts/partials.js`).
